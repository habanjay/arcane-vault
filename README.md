# Arcane Vault

Arcane Vault is a password-manager project with a React client prototype and
an ASP.NET Core API backed by SQL Server.

## Documentation

- [Getting started](docs/getting-started.md) — prerequisites, database setup,
  and running the app locally.
- [API reference](docs/api.md) — routes, request conventions, and response
  examples.
- [Database setup](docs/database.md) — SQL Server configuration and
  secret-protection key storage.
- [Data model](docs/erd.md) — schema and entity relationships.

The client is currently a UI prototype and uses local mock authentication; it
is not yet connected to the API. See the [API reference](docs/api.md) to
explore the backend independently.
